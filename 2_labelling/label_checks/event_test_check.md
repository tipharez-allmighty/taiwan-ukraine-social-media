# Label check: random sample of event-test comments where both models agreed

300 comments drawn at random (seed 20261020) from the 9,275 event-test comments (posted 10 days before to 10 days after a testable event) where Claude Opus 5 and Claude Sonnet 5 gave the same value on all six labels. These labels were kept without human review. The 303 agreed event comments that were already in the main dataset are left out, since they belong to the main sample's pool.

**How to fill in:** for each comment, read the six labels. If all are right, leave **Correct?** as `yes`. If any label is wrong, write `no` and list the fix in **Fix**, e.g. `CT ✅→❌, DUS ❌→✅`, with a short reason. Judge each label by the same rules as the labelling instructions.

Abbreviations: CU critical of Ukraine · SU supportive of Ukraine · CT critical of Taiwan · ST supportive of Taiwan · DUS disappointed with the US · BNE blames NATO expansion
